# Product photos

Put frame photos here as `.jpg`. The site shows them automatically; any model without a photo keeps its drawn frame.

**File name = model number + `_` + colour code**, in capitals, with spaces and symbols (`/`, `.`, spaces) turned into `-`:

| Product | Colour | File |
|---|---|---|
| Ray-Ban RB3025 | 003/3F | `RB3025_003-3F.jpg` |
| Carrera CA 387/C | PJP | `CA-387-C_PJP.jpg` |
| Gucci GG0467S | 006 | `GG0467S_006.jpg` |

A file named with the model only (e.g. `RB3025.jpg`) is used for every colour of that model that has no photo of its own.

Tips: a square or 4:3 image on a white or transparent-looking light background, about 1200 px wide, under 300 KB.
